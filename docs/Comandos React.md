## 1.Crear proyecto React + Vite con npm:

command: `npm create vite@latest nombre-del-proyecto`

Este comando creará un nuevo proyecto de React utilizando Vite como herramienta de construcción. Asegúrate de reemplazar "nombre-del-proyecto" con el nombre que desees para tu proyecto.

## 2.Ejecutar el proyecto:

command: `cd nombre-del-proyecto`

command: `npm install`: Este comando instalará todas las dependencias necesarias para tu proyecto.

command: `npm run dev`
